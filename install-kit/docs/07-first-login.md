# 7. First Login & Admin Setup

After installation, open `http://<server-address>/setup` from a browser on the institutional LAN. The one-time setup form creates the institute and its initial administrator on this server.

Use an institute-controlled administrator email address and choose a unique, strong password in the setup form. No shared default administrator credentials are created, and no hosted account or provisioning action is required.

After setup completes, sign in with the administrator account you created and complete this checklist:

1. ✅ Create departments, programmes, intakes, and courses.
2. ✅ Set up the academic calendar for the current year.
3. ✅ Create staff accounts and assign only the roles each person needs.
4. ✅ Import student records using the approved AMIS import process, if applicable.
5. ✅ Publish a **config version** to enable the modules required by the institution (Admissions, Enrolment, Marks, Fees, Clearance, Alumni).

> Until a config version is published, end users see "module not enabled" notices.

The setup page is for first-run initialization only. If an institute is already configured, it will reject another setup attempt.
